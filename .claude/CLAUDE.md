# Instrucciones para el desarrollo frontend de Fono

1. Siempre revisar 'Specs.md' antes de hacer cualquier cambio y respetarlo al 100%.
2. Todos los cambios se deben aprobar primero en el ambiente local.
3. No se realizaran comandos 'ng build' a menos que sean solicitados.
4. Cuando se solicite hacer un comando 'ng build' se debe realizar y entregar el proyecto compilado en un .zip
